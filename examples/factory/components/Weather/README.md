# Weather

[English](README.md) | [简体中文](README_ZH.md)

## What It Does

Displays city, temperature, weather condition, humidity and wind information in the monochrome layout. Networking uses the shared background service.

## Hardware Required

ESP32-S3-Touch-RLCD-4.2B with the peripherals used by this application.

## How to Run

Build and flash the [factory application](../../README.md), then open the corresponding desktop icon.

## Expected Result

Connect to an Internet-enabled Wi-Fi network. The default hotspot is `weather-wifi` with password `12345678`; network setup is available in Settings.

See the [Chinese usage guide](README_ZH.md) for the existing detailed component notes.

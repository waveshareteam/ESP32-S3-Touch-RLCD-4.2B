# Photo album

[English](README.md) | [简体中文](README_ZH.md)

## What It Does

Decodes JPEG files from the SD card, scales them and converts them to a monochrome dithered image below the shared application header.

## Hardware Required

ESP32-S3-Touch-RLCD-4.2B with the peripherals used by this application.

## How to Run

Build and flash the [factory application](../../README.md), then open the corresponding desktop icon.

## Expected Result

Use a FAT32 microSD card and follow the image-directory requirements in the Chinese usage guide. The BSP manages SDMMC access.

## Troubleshooting

See the [Chinese usage guide](README_ZH.md) for the existing detailed component notes.

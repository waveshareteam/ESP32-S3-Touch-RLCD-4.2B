# Mic Test

[English](README.md) | [简体中文](README_ZH.md)

400×300 黑白双麦克风测试，注册在桌面第二页，图标由 C5-3.5 的 Mic Test 图案转换为原生 64×64 黑底白色 I1 位图。采用 `rlcd_ui` 的统一黑底白字顶栏，左侧图标和名称，右侧白色返回箭头，无按钮底色、边框和按下反色。两路音量条为胶囊形，5 秒录音进度条保留 5 像素高的直角样式。

## 使用

- 打开后分别显示 MIC1、MIC2 的实时 RMS 音量，范围为 -60～0 dBFS。它是数字录音电平，不是声压计的 dB SPL；数值为未经声学校准的参考，-60 同时表示低于显示范围。
- Record 同时录制两路原始 PCM，默认 5 秒后停止；Stop 可提前结束并保留已录内容。重录覆盖上一次录音。
- 录音后分别点击 MIC1、MIC2 试听，单路原始音频复制到左右输出，不混合另一只麦克风。播放时可点击 Stop。
- CLIPPED 表示该路检测到接近数字满幅的采样，保持到重新录音或重新打开，不代表麦克风自动判定通过。靠近两只麦克风分别说话并试听，检查无声、失真或明显通道差异；两路都收到声音属于正常串音。
- 录音时间右侧显示共享的播放音量，沿用 Settings；0% 时试听静音，不自动提高音量。
- 右上角返回箭头关闭测试；上滑暂停后重新打开，会保留已完成录音并恢复采集。暂停或退出时中断的未完成录音不保留。退出释放录音内存，无 SD 卡和文件写入。

## 音频配置

ES7210 的 4 路 TDM 槽位沿用原 BSP：slot0=MIC1、slot1=MIC3 回声参考、slot2=MIC2、slot3=未使用 MIC4。测试仅提取 slot0、slot2；MIC3 不参与音量显示、存储或试听。输入为 16 kHz、16 bit，两路使用同一固定模拟增益 24 dB，不启动 AFE、AEC、自动增益、降噪或唤醒词处理。每次打开输入先丢弃 200 ms 稳定期数据。

两路交织录音存入 PSRAM：16000×5×2×2=320000 字节。独立音频任务使用 PSRAM 栈，I2S 读写有超时，UI 每 100 ms 读取快照，仅变化时更新文本和进度。UI 不直接读写 I2S 或 codec。

Mic Test 通过新增 `BSP_AUDIO_OWNER_MIC_TEST` 占用原有音频会话，与 Music、小智互斥，不使用小智的身份占用音频。原 `bsp_audio_voice_*` 接口同时服务小智和 Mic Test；小智原有默认行为保留，Mic Test 打开输出时默认静音。录音和实时监听时关闭功放，试听先关闭输入 codec，仅打开输出，结束后再恢复输入，避免边录边播。

暂停/关闭时先通知并等待音频任务完成 I/O、关闭 codec 和释放会话，再用 `vTaskDeleteWithCaps` 删除任务。关闭失败保留音频所有权，Retry 时先尝试清理，避免其他 APP 在未关闭的 codec 上启动。采集或资源分配失败会显示错误及 Retry，不自动判定硬件损坏。

## 验证

编译检查使用 ESP-IDF 5.5.4 / LVGL 9.5.0。实际双路采集、音量差异、试听、暂停恢复，以及与 Music/AIChats 连续切换仍需上板验证。本测试验证原始录放音，不验证 MIC3 回声参考或 AEC 效果。

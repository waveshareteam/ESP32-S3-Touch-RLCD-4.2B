# Sensor display

[English](README.md) | [简体中文](README_ZH.md)

## What It Does

Displays RTC date/time alongside temperature and humidity in monochrome cards. Hardware access is provided by the BSP.

## Hardware Required

ESP32-S3-Touch-RLCD-4.2B with the peripherals used by this application.

## How to Run

Build and flash the [factory application](../../README.md), then open the corresponding desktop icon.

## Expected Result

Open Sensor from the desktop. Invalid readings are displayed as placeholders.

# 出厂应用

[English](README.md) | [简体中文](README_ZH.md)

## 功能

显示 400×300 单色应用桌面，包含画板、游戏、天气、相册、传感器、设置、音乐、语音聊天和硬件测试应用。

## 硬件需求

ESP32-S3-Touch-RLCD-4.2B、USB 数据线及匹配的扬声器；使用 SD 相册或音乐时需要 FAT32 microSD 卡。

## 怎么运行

使用 ESP-IDF 6.0.2，在当前目录运行 `idf.py build flash monitor`。

## 预期现象

启动后显示单色桌面，轻点图标进入应用。

Display Test 循环显示全屏黑色 10 秒、白色 5 秒，双击屏幕任意位置退出。

## 常见问题

联网应用需要互联网连接；反射式屏幕没有背光，需要环境光照明。

# ESP32-S3-Touch-RLCD-4.2B 出厂固件使用说明

[English](README.md) | [简体中文](README_ZH.md)

接上 USB 电源后，就可以在屏幕上体验画板、相册、音乐、语音聊天和硬件测试等 11 个应用。下面从第一次上电开始，介绍每个功能怎么用。

## 1. 第一次拿到板子，先这样试

1. 把板子放在光线充足的地方，再接通 USB 电源。这块屏幕**没有背光**，需要借助环境光才能看清。
2. 等屏幕出现应用图标，轻点 **Drawing（画板）**，在空白区域用手指画几笔。
3. 点击右上角 **Clear（清空）**，画面应被清空；再点击左上角 **Back（返回）**，回到桌面。
4. 在桌面向左滑动，找到第二页的 **Button Test（按键测试）**，按下并松开板上的 Custom 和 BOOT 按键。两项都显示 PASS，就完成了一次简单体验。
5. 点击右上角返回箭头，回到桌面。接下来可以先联网，也可以继续体验不需要网络的应用。

**找不到应用时，先左右滑动桌面。** 第一页有 Drawing、AIChats、Weather、Music、2048、Photos、Sensor、Settings；第二页有 Button Test、Display Test、Mic Test。

### 想体验什么，需要准备什么？

| 想体验的功能 | 需要准备 |
| --- | --- |
| 画板、2048、屏幕/按键测试、温湿度显示 | 接通电源即可 |
| 自动显示北京时间、查看天气 | 能上网的 2.4 GHz Wi-Fi |
| 语音聊天 | 能上网的 2.4 GHz Wi-Fi、匹配的扬声器，首次使用还需绑定小智设备 |
| 相册 | FAT32 格式的 microSD 卡，以及 JPG 图片 |
| 音乐 | FAT32 格式的 microSD 卡、MP3 文件、匹配的扬声器 |
| 麦克风录音回放 | 匹配的扬声器；录音不需要 SD 卡 |

### 怎么返回桌面？

- **一般应用**：点右上角返回箭头；Drawing 的 Back 在左上角。
- **全屏看照片时**：从图片中间向上滑，先回到文件列表，再点右上角返回箭头。
- **Display Test 黑白屏测试时**：快速连续点击屏幕两下退出。
- 从屏幕最底部向上快速滑动，也可以从大部分应用返回桌面。使用音乐、语音聊天或录音后，建议点应用自己的返回按钮，再打开其他应用。

## 2. 让板子连上 Wi-Fi

连接成功后，桌面可以自动显示北京时间，Weather 可以获取天气，AIChats 可以连接语音服务。

### 用手机设置网络

1. 在板子的桌面点击 **Settings（设置）**，再点 **Network setup（配网）**。操作完成前，让板子停留在这个页面。
2. 用手机扫描屏幕上的二维码，连接板子发出的 Wi-Fi。名称类似 **RLCD4.2-xxxxxx**，密码是 **12345678**。也可以在手机的 Wi-Fi 列表中手动找到并连接它。
3. 手机如果提示“此网络无法上网”，选择**仍然连接/保持连接**。这一步只是让手机连上板子，属于正常现象。
4. 手机可能自动弹出设置网页。如果没有弹出，打开手机浏览器，在**地址栏**输入 **http://192.168.4.1**。
5. 在网页中填写家里路由器或另一个手机热点的信息：

   | 网页上的名称 | 该填什么 |
   | --- | --- |
   | Network name (SSID) | 要让板子连接的 Wi-Fi 名称 |
   | Password | 这个 Wi-Fi 的密码 |
   | Connect and Save | 填好后，点击此按钮连接并保存 |

6. 等到网页显示 **Connected and saved（已连接并保存）**，说明设置成功。大约 5 秒后，板子会关闭自己发出的热点，手机断开该热点是正常的。
7. 在板子上返回桌面，等待时间更新。以后再次上电，板子会自动连接刚才保存的 Wi-Fi。

**请使用 2.4 GHz Wi-Fi，5 GHz 网络不能使用。** 更换路由器或密码后，重新按上述步骤设置即可。

如果网页打不开，先确认：板子还停留在 Network setup 页面；手机仍连着板子的热点；输入的是 `http://192.168.4.1`，而不是 HTTPS 或搜索关键词。

Settings 中的 **Wi-Fi** 页面只能查看附近有哪些网络，**连接网络请进入 Network setup**。

### 另一种方式：使用预设热点

如果还没有保存过 Wi-Fi，也可以在手机上开启一个名称为 `weather-wifi`、密码为 `12345678` 的 2.4 GHz 热点，并打开移动数据。板子会尝试连接它。

已经保存过其他 Wi-Fi 时，会优先连接已保存的网络。这时要换网络，请使用上面的 Network setup。

### 怎么确认时间正常？

- 刚开机显示 `--:--`：还没取得网络时间，先联网并稍等。
- 联网校时成功：桌面显示北京时间（UTC+8）。
- 校时后断网：时间继续走，不会马上消失。
- 断电再上电：需要重新联网取得时间。

## 3. 放入自己的照片和音乐

### 先准备 SD 卡

1. 准备一张 **FAT32** 格式的 microSD 卡。若需要格式化，请先备份卡内文件；格式化会清除原有内容。本固件不支持 exFAT。
2. 用读卡器把卡接到电脑上，打开 SD 卡，直接新建两个文件夹：**photo** 和 **music**。“根目录”就是打开 SD 卡后看到的第一层，不要把这两个文件夹放进其他文件夹里。
3. 图片放进 photo，音乐放进 music。例如：

   ```text
   SD card/
   ├── photo/
   │   ├── 01_cat.jpg
   │   └── 02_landscape.jpg
   └── music/
       ├── 01_song.mp3
       └── 02_song.mp3
   ```

4. 在电脑上安全弹出 SD 卡，关闭板子电源，插好卡后再上电。
5. 打开板子的 **Settings → SD Card**。板子开机时会自动检测卡；如果显示 **Checking...**，稍等后查看容量。没有检测到时，检查插卡和格式，再点 **Check card（检测卡）**。

### 第一次看照片，建议先用示例图

把[示例图片文件夹](components/Photos/sdcard_example/photo/)中的 JPG 文件复制到 SD 卡的 photo 文件夹，再打开板子上的 Photos。先确认示例图能显示，再换成自己的照片，更容易找到问题。

自己的照片建议这样准备：

- 在图片编辑软件中调整为 **400×300 像素**，导出为普通 **JPG/JPEG**。图片摆正后再导出，板子不会自动纠正照片方向。
- 导出时如有“渐进式/Progressive”选项，请关闭；颜色选择 RGB 或灰度，不要选 CMYK。
- 单张文件不超过 **2 MiB**，最多放 **128 张**。较大的原图还要求宽×高不超过 **2,097,152 像素**。
- 文件名建议用 `01_cat.jpg` 这样的英文、数字和下划线，方便显示和排序。
- PNG、GIF、HEIC 等格式需要真正转换成 JPG，直接把文件名后缀改成 `.jpg` 无效。

这是一块黑白屏。彩色照片可以打开，但会转成黑白显示，阴影处可能出现点状纹理。想要轮廓更清楚，建议提前做好高对比度黑白照片。比例不是 4:3 的图片会保留白边，避免把画面拉变形。

### 音乐怎么准备？

把真正的 **MP3** 文件放进 music 文件夹，建议命名为 `01_song.mp3`、`02_song.mp3`。不要放进子文件夹；WAV、FLAC 等文件需要先转换为 MP3。

## 4. 每个应用怎么用

### Drawing：画板

1. 点击桌面上的 **Drawing**，在空白区域按住并拖动手指，画出黑色线条。
2. 点击右上角 **Clear**，清空整张画布。
3. 点击左上角 **Back**，返回桌面。

画板用于临时绘画，不会保存图片；重新打开时是空白画布。

### AIChats：和小智聊天

1. 先按第 2 节连好网络，并确认扬声器已连接，再打开 **AIChats**。
2. 如果屏幕显示激活码，按屏幕给出的提示，在小智控制台添加设备并填写激活码。完成绑定后，等待设备进入待机状态。
3. 对着板子说“**你好小智**”，或者轻点 **Talk（说话）**，然后说出问题，例如“今天星期几？”。
4. 说完后稍等，屏幕会显示对话文字，扬声器播放回复。点击 **Stop（停止）** 可以结束当前对话；也可以用唤醒词打断回复。
5. 点击右上角返回箭头退出。退出后，板子不会继续在后台监听唤醒词。

听不到回复时，先到 Settings 把音量调高，确认不是 0，再检查扬声器。出现网络错误时，检查 Wi-Fi 是否能上网。

### Weather：看天气

1. 连好网络，打开 **Weather**，稍等后查看天气、温度、湿度和风向等信息。
2. 想立即更新，轻点页面中的**天气图案**。正常情况下，页面也会大约每 5 分钟自动更新。
3. 点击右上角返回箭头退出。

当前显示的是**深圳天气**，不会跟着设备所在地自动变化。断网后旧数据可能还留在页面上，注意查看更新时间；需要更改城市时，见文末开发说明。

### Music：播放音乐

1. 按第 3 节放好 MP3 文件，连接扬声器，再打开 **Music**。
2. 点击中间的**播放按钮**开始播放；再点一次暂停，再点继续播放。
3. 点上一首/下一首按钮切换歌曲，文件按名称排序。
4. 点右上角返回箭头退出并停止播放；从页面中间向上滑也可以退出。

一首歌播放完会停止，想听下一首请手动切换。进度条用于查看播放位置，不能拖动。页面上的 Music Player / Chill Vibes 是装饰文字，不是歌曲名称。

### 2048：数字合并游戏

1. 打开 **2048**，在棋盘内部向上、下、左、右滑动，让数字方块移动。
2. 相同数字碰到一起就会合并，例如两个 2 合成一个 4，继续尝试合成 2048。
3. 想重玩时，点 **New Game（新游戏）**；结束页面也可以重新开始。
4. 点击右上角返回箭头退出。

游戏进度不自动保存，最高分在本次通电期间保留。请在棋盘中间滑动，避免从屏幕边缘开始而触发返回操作。

### Photos：全屏看照片

1. 按第 3 节放好 JPG 文件，打开 **Photos**，等待出现文件列表。
2. 点一个文件名，照片会铺在全屏区域显示；此时没有顶部栏或返回按钮。
3. **在图片中间向左滑看下一张，向右滑看上一张**，到最后一张后会循环。
4. **在图片中间向上滑回到文件列表**，再点右上角返回箭头退出。
5. 换过 SD 卡内的图片后，点列表页的 **Rescan（重新扫描）**，再打开图片。

照片需要手动滑动切换，不会自动轮播。这一应用只读取 SD 卡图片，不会删除或修改原图。

### Sensor：看温湿度和测试时间

1. 打开 **Sensor**，就可以查看温度、湿度和时间。
2. 温湿度约每 5 秒刷新一次，时间每秒变化；刚打开时若还是占位符，先等一会儿。
3. 点击右上角返回箭头退出。

**这里的时间是用来测试板载时钟芯片的，不是桌面的北京时间。** 测试从 **2026-04-22 23:59:00** 开始，重新进入或恢复应用时可能重新开始计时。查看实际北京时间，请看联网后的桌面。

### Settings：调音量、连网络、查 SD 卡

打开 **Settings** 后，按需要选择：

| 页面上的名称 | 怎么用 |
| --- | --- |
| Volume（音量） | 拖动滑条调节声音，向右更大，0 为静音；松手后自动保存，下次开机仍使用此音量 |
| Wi-Fi | 查看附近的 Wi-Fi 名称和信号情况 |
| Network setup（配网） | 让板子连接自己的 Wi-Fi，完整步骤见第 2 节 |
| SD Card | 查看卡是否识别，以及总容量和剩余空间；Check card 可以重新检测 |
| About（关于） | 查看固件版本和设备信息 |

进入子页面后，点返回箭头先回到设置主页，再点一次回桌面。调高音量后，需要回到音乐或录音页面点击播放，声音才会开始。

### Button Test：检查实体按键

1. 打开 **Button Test**，按下再松开板子的 **Custom** 按键，观察状态和计数变化。
2. 再按下并松开 **BOOT**。每项显示 **PASS（通过）**，两项都完成时显示 **2/2**。
3. 点刷新图标可以清空结果，再测一次；右上角返回箭头退出。

请等板子正常启动后再测 BOOT。不要按住 BOOT 再上电，否则可能进入下载模式而不显示桌面。

### Display Test：检查黑白显示

1. 打开 **Display Test**，屏幕先保持**全黑 10 秒**，再保持**全白 5 秒**，之后反复循环。
2. 在光线充足的环境中观察屏幕，检查是否有一直不变的点或显示不均匀的位置。
3. 想退出时，**快速连续点击屏幕两下**。如果没退出，再加快两次点击的间隔。

### Mic Test：录一段声音再听听

1. 连接好扬声器，打开 **Mic Test**。对着板子说话，MIC1、MIC2 的电平条应随声音变化。
2. 点 **Record（录音）**，说一句“这是麦克风测试”，等待约 5 秒录音结束；也可以点 **Stop** 提前结束。
3. 分别点击 **MIC1** 和 **MIC2** 的播放按钮，听听两个麦克风录下的声音。
4. 想重录，再点 Record，新的录音会覆盖上一段；右上角返回箭头退出。

录音只用于本次试听，不会保存到 SD 卡。没有声音时，先检查扬声器和 Settings 音量。出现 **CLIPPED** 时，离麦克风远一点或小声一些再录；它表示声音太大，录音可能失真。

## 5. 电量显示怎么看？

桌面的百分比是**根据电池电压估算的剩余电量**，可以用来观察大致变化，不代表精确容量或还能使用多久。刚开机显示 `--%` 时，先等几秒。

为了让读数稳定，百分比不会跟着每次电压波动立即变化，充电或播放声音时也可能出现偏差。是否正在充电，请看板载充电指示灯；屏幕上没有充电动画。

## 6. 遇到问题，先看这里

| 遇到的情况 | 可以先这样做 |
| --- | --- |
| 屏幕在暗处看不清 | 移到明亮处，这块屏幕没有背光 |
| 桌面一直显示 `--:--` | 按第 2 节联网，确认 Wi-Fi 能上网，再等一会儿 |
| 手机连板子的热点后提示不能上网 | 选择保持连接，然后用浏览器打开 http://192.168.4.1 |
| 配网页打不开 | 保持 Network setup 页面打开，检查手机有没有自动切回其他 Wi-Fi |
| Wi-Fi 名称点了没反应 | 这是扫描页；返回后进入 Network setup 配网 |
| 网页提示连接成功但保存失败 | 重新打开配网流程再试，保存成功后才能在重启时自动连接 |
| 插卡后相册或音乐是空的 | 先到 Settings → SD Card 查卡，再检查 photo/music 文件夹是否在卡的第一层 |
| SD Card 没显示容量 | 检查插卡及 FAT32 格式，点 Check card 再试 |
| 自己的照片打不开 | 先试第 3 节的示例图，再把自己的照片重新导出成 400×300 普通 JPG |
| 照片显示方向不对 | 在电脑上旋转并重新导出 JPG 后再复制，点 Rescan 刷新 |
| 照片有很多小点 | 黑白转换会产生点状纹理，可尝试提前做好高对比度黑白图 |
| 全屏照片不知道怎么退出 | 在图片中间向上滑，回列表后点返回箭头 |
| 屏幕测试没有文字，一直黑着 | 等 10 秒看是否转白；快速双击屏幕可以退出 |
| 音乐或录音播放没有声音 | 检查扬声器，调高 Settings 音量，用返回按钮退出其他音频应用后重试 |
| 天气还是旧的 | 检查网络，轻点天气图案刷新，并查看更新时间 |
| Sensor 的时间和桌面不同 | Sensor 显示时钟芯片测试时间，桌面才是联网后的北京时间 |

## 7. 想修改代码或重新烧录

日常使用按上面的步骤操作即可。需要自行修改时，本目录是出厂固件源码，使用 **ESP-IDF v6.0.2、LVGL v9.5.0**。

在本目录打开 ESP-IDF 终端，依次执行：

```sh
idf.py set-target esp32s3
idf.py build
idf.py flash monitor
```

`Ctrl+]` 退出串口监视器。更换天气城市可运行 `idf.py menuconfig`，在 **RLCD Weather** 中修改城市配置，再重新编译烧录。

如果使用适用于本产品的**完整合并 BIN**，烧录地址为 **0x0**，芯片 ESP32-S3，Flash 16 MB，DIO、80 MHz。工程生成的 `build/esp32_s3_touch_rlcd_4_2b.bin` 只是应用镜像，不能当成完整固件烧录到 0x0。首次从源码烧录请用 `idf.py flash`，让工具按 `build/flash_args` 同时写入语音模型等所需内容。

擦除或烧录完整镜像可能清除保存的 Wi-Fi、音量和设备激活信息，之后按前面的步骤重新设置；SD 卡里的文件不受影响。

硬件接口统一放在 [esp32_s3_touch_rlcd_4_2b BSP](components/esp32_s3_touch_rlcd_4_2b/) 中。进一步了解实现，可查看[相册](components/Photos/README_ZH.md)、[天气](components/Weather/README_ZH.md)、[设置](components/Settings/README_ZH.md)、[音乐](components/Music/README_ZH.md)和[麦克风](components/MicTest/README_ZH.md)组件说明。

# ESP32-S3-Touch-RLCD-4.2B 出厂固件使用说明

[English](README.md) | [简体中文](README_ZH.md)

本说明适用于本目录源码对应的出厂固件。已预装该固件的设备可以直接使用，无需安装开发环境或重新编译。

## 1. 首次使用

### 准备物品

- ESP32-S3-Touch-RLCD-4.2B 和 USB 供电线；烧录时需使用支持数据传输的 USB 线。
- 光线充足的使用环境：400×300 黑白反射式 LCD **没有背光**，在暗处看不清并不代表未开机。
- 使用音乐或相册时，准备 FAT32 格式的 microSD 卡；不使用这些功能时可以不插卡。
- 使用音乐、录音回放或语音聊天时，连接匹配的扬声器。
- 使用天气、网络校时或语音聊天时，准备可访问互联网的 **2.4 GHz Wi-Fi**。

### 上电后怎么操作

1. 接通 USB 电源，等待应用桌面出现。
2. 轻点图标打开应用，左右滑动桌面切换页面。
3. 如需联网，先进入 **Settings → Network setup**，按照下一节配网。
4. 如需查看图片或播放音乐，先按照第 4 节准备 SD 卡文件。
5. 大部分应用通过右上角返回箭头退出；相册全屏页和屏幕测试的退出方式见下表。

桌面第一页为 Drawing、AIChats、Weather、Music、2048、Photos、Sensor、Settings；第二页为 Button Test、Display Test、Mic Test。

## 2. 桌面与返回操作

| 操作/显示 | 说明 |
| --- | --- |
| 轻点桌面图标 | 打开对应应用 |
| 左右滑动桌面 | 切换应用页面 |
| 应用返回箭头 | 大部分应用在右上角；Drawing 的 Back 在左上角 |
| 从屏幕底部边缘快速向上滑 | 大部分应用返回桌面；应用可能进入暂停状态，音频应用建议使用自身返回按钮退出 |
| Photos 全屏看图 | 从画面中间向上滑返回文件列表，再点右上角返回箭头退出 |
| Display Test | 双击屏幕任意位置退出，两次点击间隔约 400 ms 以内；该应用不使用系统导航手势 |
| 桌面 Custom 按键 | 切换桌面表情 |
| Wi-Fi 图标 | 表示连接状态，不表示信号强度 |
| 电池 `--%` | 尚未取得有效电量数据，或缓存数据已失效 |

桌面时间在本次上电首次网络校时前显示 `--:--`。校时成功后显示北京时间（UTC+8）；随后断网，系统时钟仍继续走时。重新上电后需要再次联网校时。**桌面时间与 Sensor 内的 RTC 工厂测试时间是两个独立的显示来源。**

## 3. 连接 Wi-Fi

### 推荐：使用手机配网

1. 在设备上进入 **Settings → Network setup**，配网过程中保持此页面打开。
2. 用手机扫描屏幕二维码，连接设备开启的 `RLCD4.2-xxxxxx` 热点，密码为 `12345678`。二维码用于连接设备热点，并非直接打开路由器设置页面。
3. 手机提示“此网络无法访问互联网”时，选择继续连接，暂时不要切换回其他 Wi-Fi。
4. 如未自动弹出配网页面，在浏览器输入 **http://192.168.4.1**，不要使用 HTTPS。手机此时必须仍连接设备热点。
5. 在 **Network name (SSID)** 和 **Password** 中填写目标 2.4 GHz 路由器或手机热点信息，点击 **Connect and Save**。
6. 等待页面显示 **Connected and saved**。连接信息会保存，设备热点在成功后约 5 秒关闭；手机可切回日常网络。
7. 返回桌面，等待网络校时；打开 Weather 或 AIChats 使用联网功能。

下次启动优先连接已保存的网络。更换网络时重新执行上述步骤。若页面提示已连接但保存失败，本次连接可能正常，重启后仍可能需要重新配网。

**Settings → Wi-Fi 仅用于扫描附近网络**，不能点选网络完成连接。设备普通连接失败时也不会自动开启配网热点，需要手动进入 Network setup。

### 使用预设测试热点

没有已保存的网络信息时，固件尝试连接以下测试热点：

| 项目 | 内容 |
| --- | --- |
| 名称 | `weather-wifi` |
| 密码 | `12345678` |
| 频段 | 2.4 GHz |

手机热点需开启移动数据；如有兼容性选项，请选择 2.4 GHz。**已保存的网络优先于此预设热点**，无需为了日常使用修改自己的路由器名称。

已连接 Wi-Fi 不等于可以访问互联网。网络校时、天气和语音服务还需要对应服务器可访问；画板、相册和本地硬件测试等功能可以离线使用。

## 4. 准备 SD 卡

使用 **FAT32** 文件系统，当前配置不支持 exFAT。建议关机后插拔 SD 卡，避免在读取文件时拔卡。

设备每次启动会在后台检测一次 SD 卡并读取容量。进入 **Settings → SD Card** 可查看结果，不需要先手动点击检测；若仍显示 Checking，请稍候。插入、更换卡或修改文件后，可点击 **Check card** 手动刷新。该功能不是持续热插拔检测，也不提供格式化或弹出操作。

在 SD 卡根目录创建以下文件夹，文件直接放在对应目录，不要再套子文件夹：

```text
SD card root/
├── photo/
│   ├── 01_landscape.jpg
│   └── 02_cat.jpeg
└── music/
    ├── 01_song.mp3
    └── 02_song.mp3
```

推荐使用英文、数字和下划线命名，数字前缀便于控制按文件名排序的顺序；部分非英文字符可能无法正常显示。

### 图片要求

| 项目 | 要求 |
| --- | --- |
| 目录 | SD 卡根目录下的 `photo` |
| 格式 | 基线 JPEG，扩展名 `.jpg` 或 `.jpeg`，大小写均可 |
| 编码 | 8 位 RGB、YCbCr 或灰度 JPEG |
| 推荐分辨率 | 400×300 |
| 单文件上限 | 2 MiB |
| 像素总数上限 | 宽×高不超过 2,097,152 像素 |
| 文件数量上限 | 128 张 |
| 不支持 | 渐进式 JPEG、CMYK JPEG、PNG、BMP、GIF、HEIC |

其他宽高比图片会等比缩放，空白区域显示白色，不会拉伸铺满。程序不自动按 EXIF 旋转图片，请在电脑上旋转后重新导出。

屏幕只有黑白两种像素，彩色或灰度照片显示时会转换成黑白抖动图案，出现点状纹理属于正常现象。提前准备对比清晰的 400×300 黑白 JPG，可以更好地控制显示效果。

可直接复制[示例图片](components/Photos/sdcard_example/photo/)到 SD 卡的 `photo` 目录进行测试。

### 音乐要求

文件放在 SD 卡根目录下的 `music` 文件夹，使用实际编码为 MP3 的 `.mp3` 文件；仅修改扩展名不能转换格式。不扫描子目录，不支持 WAV、FLAC。

## 5. 应用功能一览

| 应用 | 功能 | 额外条件 |
| --- | --- | --- |
| Drawing | 黑白触摸画板 | 无 |
| AIChats | 小智语音聊天 | 互联网、服务激活、扬声器 |
| Weather | 天气信息 | 互联网 |
| Music | MP3 播放 | SD 卡、扬声器 |
| 2048 | 数字合并游戏 | 无 |
| Photos | 全屏静态图片浏览 | SD 卡及 JPEG 图片 |
| Sensor | RTC、温度、湿度 | 板载传感器 |
| Settings | 音量、网络、SD 卡和设备信息 | 按功能选择 |
| Button Test | 按键测试 | 板载 Custom、BOOT 按键 |
| Display Test | 全黑/全白屏幕测试 | 无 |
| Mic Test | 双麦克风电平、录音与回放 | 回放需要扬声器 |

### Drawing：画板

在画布中按住并拖动手指绘画，使用固定黑色画笔。右上角 **Clear** 清空画布，左上角 **Back** 退出。当前不提供橡皮擦、撤销或保存到 SD 卡功能；重新打开画板会清空画面。

### AIChats：语音聊天

1. 先完成联网，再打开 AIChats。
2. 首次使用未绑定的设备时，按照屏幕提示在小智控制台添加设备并输入激活码。
3. 待设备就绪后，说“**你好小智**”唤醒，或轻点 **Talk** 开始对话。
4. 说完后等待服务识别并回复；**Stop** 可取消当前交互，唤醒词也可用于打断回复。
5. 聊天文字区域可上下滑动，右上角返回箭头退出。

声音大小使用 Settings 的共享音量，音量为 0 时无声。退出应用会停止唤醒监听并释放音频资源。网络或服务异常时，先恢复网络并按页面状态等待重连。完整烧录时需包含语音模型，不能只烧录应用 BIN 后就假定唤醒功能完整。

### Weather：天气

打开后自动获取天气，显示城市、更新时间、天气状况、温度、湿度、风速和风向。当前默认城市为 **深圳**，不是通过 GPS 或 Wi-Fi 自动定位。

轻点天气插图可手动刷新。成功后约每 5 分钟更新一次，失败后约 30 秒重试；断网时可保留本次运行中已成功取得的数据，请结合更新时间和状态提示判断。右上角返回箭头退出。

如需更换默认城市，由开发者在 `menuconfig → RLCD Weather` 中调整并重新编译。

### Music：音乐

1. 按第 4 节准备 SD 卡后打开 Music，程序扫描文件，初始为暂停状态。
2. 点击播放/暂停按钮控制音乐；暂停后再次播放会继续当前位置。
3. 上一首、下一首循环切换曲目，并保持当前播放或暂停状态。
4. 一首播放完会停止，不自动跳到下一首；再次播放可从该曲开头开始。
5. 右上角返回，或从页面中间向上滑，关闭播放器并停止声音。

进度条仅显示进度，不能拖动定位。封面上的 **Music Player / Chill Vibes** 是固定装饰文字，不是实际文件名或歌曲标签。读取失败时，先检查卡和文件，再点击中央按钮重新扫描，随后播放。

### 2048：数字游戏

在棋盘内部上下左右滑动，让相同数字合并，累计得分。**New Game** 重新开始；胜利或无法继续合并时，可通过结果页面重开。当前最高分保留在本次通电会话中，关机后不保证保留，游戏进度也不自动保存。右上角返回箭头退出。

请从棋盘内部滑动，避免从屏幕边缘开始而触发系统导航。

### Photos：相册

1. 打开 Photos，等待扫描 `photo` 目录并显示文件列表。
2. 轻点文件名，全屏显示图片；此时不显示顶部标题栏或状态栏。
3. 从画面中间向左滑看下一张，向右滑看上一张，到末尾会循环切换。
4. **从画面中间向上滑返回文件列表**；再点击列表右上角返回箭头退出。
5. 文件有变动时，使用 **Rescan** 刷新列表和图片缓存。

当前为手动切换的静态相册，没有定时轮播、GIF 动画或网页上传功能。程序不会创建、删除或改写 SD 卡中的图片。开机的 SD 卡检测不会提前解码全部照片，图片在选择后读取和解码。

### Sensor：传感器

显示 PCF85063 RTC 时间及 SHTC3 温湿度。RTC 大约每秒更新，温湿度大约每 5 秒更新；读取无效时显示占位符。

**这是独立的 RTC 工厂测试页面**：初始化 RTC 时写入测试起点 **2026-04-22 23:59:00**，重新进入或恢复页面时可能重新初始化。该时间不代表北京时间，也不与桌面的网络校时结果同步。右上角返回箭头退出。

### Settings：设置

- **Volume**：共享音量 0–100，每档 5，默认 55。拖动立即生效，松开后保存，重启保留；0 为静音。若提示保存失败，可重新调整重试。
- **Wi-Fi**：扫描附近 2.4 GHz 网络，查看名称、信号、信道和加密情况，仅查看，不用于点选连接。
- **Network setup**：二维码及网页配网，详见第 3 节。
- **SD Card**：显示开机检测的挂载状态及总容量、剩余容量；Check card 手动刷新。MiB/GiB 使用二进制容量单位。
- **About**：查看固件版本、ESP-IDF、MAC、Flash、PSRAM 和屏幕等信息。

子页面返回箭头先返回设置主页，再次返回退出应用。提高音量不会自动恢复已暂停的音乐。

### Button Test：按键测试

分别按下并松开 **Custom（GPIO18）** 和 **BOOT（GPIO0）**，查看 PRESSED/RELEASED 状态和计数；完成后对应项显示 PASS，两项通过显示 2/2。刷新图标可清空测试结果，右上角返回箭头退出。

请在设备正常启动后测试 BOOT；上电或复位时按住 BOOT 可能进入下载模式。

### Display Test：屏幕测试

进入后从全黑开始，循环执行 **黑屏 10 秒 → 白屏 5 秒**，用于观察显示均匀性、亮暗点等。页面没有文字或标题，全黑不是死机。

**双击屏幕任意位置退出**，两次点击间隔约 400 ms 以内。此页面禁用系统导航手势。

### Mic Test：麦克风测试

1. 查看 MIC1、MIC2 实时电平，对着不同麦克风说话观察变化。
2. 点击 **Record** 同时录制两个通道，最长约 5 秒；**Stop** 可提前结束。
3. 分别点击 **MIC1 / MIC2** 播放按钮，听取对应通道录音；Stop 停止回放。
4. 再次录音会覆盖前一次内容。右上角返回箭头退出并释放录音资源。

录音只保存在内存中，不会写入 SD 卡。显示的 dBFS 是数字音频电平，不是环境声压级 dB SPL；CLIPPED 表示信号接近满幅，可离麦克风远一些或降低声音后重录。两个麦克风同时收到声音属于正常现象。

Music、AIChats 和 Mic Test 共用音频硬件，切换前建议使用应用自身返回按钮退出。没有回放声音时，检查扬声器接线及 Settings 音量。

## 6. 电池电量如何理解

桌面电量是根据采样电压换算的**估算剩余电量**，不是专用电量计测得的精确容量，也不提供准确的剩余使用时长预测。

固件大约每 2 秒形成一组采样结果，经过异常值剔除、滤波、滞回和显示限速后更新百分比。电压映射范围约为 3.00–4.12 V；正常情况下显示值缓慢变化，低电压时可更快下降。因此瞬时电压换算出的百分比与界面显示不同是正常的。

充电、负载和电池状态都会影响读数。当前不提供可靠的电池在位或充电状态识别，也没有屏幕充电动画；充电状态请结合板载充电指示灯判断。

## 7. 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 暗处屏幕看不清 | 反射式 LCD 无背光，请增加环境照明 |
| 开机时间显示 `--:--` | 先配网并等待互联网校时，本次上电首次成功校时前属于正常状态 |
| Wi-Fi 已连接但天气或时间不更新 | 确认网络能访问互联网及相关服务器 |
| 手机打不开 192.168.4.1 | 保持 Network setup 页面打开，手机连接设备热点，使用 HTTP，并避免自动切换网络 |
| Wi-Fi 列表不能点选连接 | 扫描页只用于查看，请使用 Network setup |
| 修改了测试热点但没有连上 | 已保存网络优先，请通过配网页面更新连接信息 |
| SD 卡未识别 | 检查插卡及 FAT32 格式，在 Settings → SD Card 点击 Check card |
| 相册列表为空 | 检查根目录 `photo`、扩展名及 JPEG 编码，点击 Rescan |
| 图片打不开或方向不对 | 按第 4 节重新导出基线 JPEG，控制大小和像素，先在电脑上旋转 |
| 照片有点状纹理 | 单色转换的抖动效果，推荐预处理为高对比度黑白图 |
| 全屏照片没有返回按钮 | 从画面中间向上滑回列表 |
| Display Test 一直黑屏 | 先等待 10 秒观察白屏，双击退出；同时检查环境光 |
| 音乐/录音回放没有声音 | 检查扬声器和共享音量，退出其他音频应用再试 |
| 音乐播放完没有换曲 | 当前设计为单曲结束停止，请手动切换 |
| Sensor 时间与桌面不一致 | Sensor 是独立 RTC 工厂测试，桌面使用网络校时 |
| 电量变化慢或与电压直算结果不同 | 电量经过滤波和显示限速，且只是电压估算值 |
| 语音聊天显示激活提示 | 按屏幕提示完成小智设备绑定；确保网络可用 |

## 8. 重新烧录与开发者说明

正常使用预装固件不需要编译。若已取得适用于本产品的**完整合并 BIN**，其烧录起始地址为 **0x0**，目标芯片为 ESP32-S3，Flash 为 16 MB，模式 DIO、频率 80 MHz。擦除或烧录完整镜像可能清除已保存的 Wi-Fi、音量及设备激活相关信息，但不会删除 SD 卡文件。

本源码工程使用 **ESP-IDF v6.0.2、LVGL v9.5.0**。在本目录的 ESP-IDF 终端运行：

```sh
idf.py set-target esp32s3
idf.py build
idf.py flash monitor
```

`Ctrl+]` 退出串口监视器。使用工程生成的烧录参数包含语音模型等分区；实际地址以 `build/flash_args` 为准。`build/esp32_s3_touch_rlcd_4_2b.bin` 是**应用分区镜像**，不是完整合并固件，不能按 0x0 烧录。

统一 BSP 位于 [esp32_s3_touch_rlcd_4_2b](components/esp32_s3_touch_rlcd_4_2b/)。更多实现细节见[相册说明](components/Photos/README_ZH.md)、[天气说明](components/Weather/README_ZH.md)、[设置说明](components/Settings/README_ZH.md)、[音乐说明](components/Music/README_ZH.md)及[麦克风说明](components/MicTest/README_ZH.md)。
